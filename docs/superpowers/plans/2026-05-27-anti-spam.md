# Anti-spam (client-side) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop casual form-bot spam on the waitlist form with three client-side guards (honeypot, time-trap, local throttle), no new infra.

**Architecture:** All logic lives inside `EmailForm` in `app.jsx`. The guards run after email validation and before `saveLead`; if any trips, the form shows the success state but skips the insert (silent no-op). Only clean submissions persist.

**Tech Stack:** React 18 (CDN) + Babel standalone (existing). No bundler, no test runner — verification is browser-based via the cached Playwright Chromium.

Replace with:
```javascript
  const submit = async (e) => {
    e.preventDefault();
    const v = email.trim();
    if (!v) { setErr(t.form_err_empty); setState("error"); return; }
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v)) { setErr(t.form_err_invalid); setState("error"); return; }

    // Anti-spam (silencioso): honeypot, time-trap e throttle local.
    // Se disparar, mostra sucesso mas NÃO grava — não tipa o bot, não polui o banco.
    const honeyFilled = honeyRef.current && honeyRef.current.value.trim() !== "";
    const tooFast = Date.now() - mountedAt.current < MIN_FILL_MS;
    let throttled = false;
    try {
      const last = Number(localStorage.getItem("nian-last-signup") || 0);
      throttled = Date.now() - last < COOLDOWN_MS;
    } catch {}
    if (honeyFilled || tooFast || throttled) { setErr(""); setState("sent"); return; }

    setErr("");
    setState("loading");
    try {
      await onSubmit?.(v);
      try { localStorage.setItem("nian-last-signup", String(Date.now())); } catch {}
      setState("sent");
    } catch (err) {
      setErr(t.form_err_generic);
      setState("error");
    }
  };
```
